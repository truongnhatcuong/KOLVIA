# Chân dung KOL demo

Sáu nhân vật hư cấu được tạo bằng công cụ imagegen tích hợp, dành cho tài khoản demo trong prisma/seed.ts. Không phải ảnh hoặc danh tính của KOL thật.

Prompt chung: “Generate a single square photorealistic natural editorial portrait for a fictional KOL profile in a Vietnamese creator marketplace website. Head and shoulders, person centered, full top of head visible, looking toward camera, friendly genuine smile, natural skin texture, soft daylight, premium editorial photography. Entirely fictional person, no resemblance to a public figure. No text, logos, borders, collage or watermark. Output suitable for a circular profile avatar.”
